## 1. 这份文档怎么用

这份文档供独立审查使用，记录当前分支实际实现了什么、修了什么、哪些只是部分实现、哪些还没做。

状态分三类：

- **已验证**：有自动化测试，或已在真实数据集上实际运行并记录结果。
- **已实现未实测**：代码和测试存在，但没有真实模型或真实浏览器验收。
- **未实现**：设计中要求，当前代码没有对应能力。

审查时请以当前提交的代码和实际运行结果为准；本文不替代设计文档，也不把“写了代码”等同于“验收通过”。

## 3. 模块实现状态

### 3.1 A 课程知识

**已验证**

- 教材 PDF 文本层读取、章节切分、范围计划、页块选择。
- 模型教材知识点提取：按页块提取、页码校验、类型归一、答案泄露拦截。
- 知识点独立复核：逐点 pass/reject/uncertain，未通过转待审。
- 知识点合并：两次独立模型判断，双方 same 才合并。
- 关系推断：候选排序、分批、结构校验、DAG 环隔离、逐条独立复核。
- 映射缺口补充：两轮模型映射 + 独立复核；找不到记缺口。
- 待审知识点登记到教师审核队列。
- 页眉重复标题合并，避免每页切一章。

**部分实现**

- 关系：34 点真实重建可产出 19 条关系，但受 180 秒预算影响只覆盖 22/34 个点；多来源组合关系和关系修复未做。
- 合并：判断结果未持久化为独立合并记录，退休 ID 映射未落库。

**未实现**

- 扫描页 OCR、图片公式、视觉证据。
- 复核不通过后的自动修复再复核循环。
- 逐题覆盖状态、变式标签审核、完整变更集。

### 3.2 B 学情

**已验证**

- 指标统计、分子分母、证据状态、掌握状态和限制。
- 错因语义诊断：只处理有书面过程、未满分、规则未解释的解答题；证据逐字回查。
- 模型失败降级：不改确定性统计，不伪造解释。
- 解答题评分：模型初评 + 第二次独立复核；不一致转待复核，不自动通过。
- 无书面过程的学生明确提示“未做模型错因解释”。

**部分实现**

- 历史已生成的学情不会自动补模型解释，需要重新分析。
- 根因链（根因错误、连带失分、独立错误）未实现。
- 诊断摘要 `summary` 没有正式生成字段。

**未实现**

- 解题步骤解析、评分点逐项语义对齐。
- 双模型评分仲裁、教师改分与复核联动。
- 师生诊断叙述、班级叙述、进展叙述。

### 3.3 C 学习方案与微课堂

**已验证**

- 规则规划器生成任务组、活动、方案审核与发布。
- 整份方案的模型独立复核：六类检查，严重问题阻止自动发布。
- 微课堂模型生成、独立复核、fail-closed 回退规则模板。
- 微课堂按学生错因和知识点分族，规则模板不再全班共用固定例题。
- 微课堂重新生成：替换旧微课堂，不重复叠加。
- 微课堂前端渲染：文字、公式、推导、对照、引用、数轴等组件的安全渲染。
- 教师意图优化：只读建议，不直接发布；教师确认后走预览→发布。

**部分实现**

- 微课堂八项复核与一次最小修复已实现；修复失败会退回规则模板，不 fail-open。
- 优化建议只有“第一个任务组的移除/调序”能直接转成可预览变更；新增、替换、跨组仍只读。
- 引用目前是知识点证据，教材原文来源仍缺。

**未实现**

## 5. 审查建议

独立审查时建议重点核对：

1. `src/study_companion/agent/expanded_tools.py` 与 `api/routes/chat.py`：工具是否真的注册、任务路由是否能到达。
2. `pipeline.py`：版本边、知识依赖、任务组字段、微课堂上下文是否真的写入。
3. `exports/service.py`：发布状态、材料引用、微课堂引用、manifest 校验是否从正式记录读取。
4. `chat/stream`：SSE 事件是否来自真实 Agent 执行，是否只在流式不可用时退化为分块。
5. `plans/edits`：是否仍存在教师直接写自然语言意图、绕过 Agent 的入口。
6. 已生成数据与代码的差异：旧版本 payload 不可回写，需重新生成或重新发布。
