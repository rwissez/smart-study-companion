# 湛知快捷启动

## 一次性准备

1. 安装 Python 3.12、uv、Node.js 22.12 及以上与 npm。
2. 仓库根目录执行 `uv sync --locked`，确认存在 `.venv\Scripts\python.exe`。
3. `frontend` 目录执行 `npm install`，确认存在 `frontend\node_modules`。
4. 复制 `.env.example` 为 `.env`。不填模型也能启动，需要模型能力时填三要素与密钥。

完整要求见 [部署与数据准备](交付/部署与数据准备.md)。

## 启动

双击项目根目录的 `启动湛知.bat`，或在桌面双击 `启动湛知.lnk`。

启动器会：

1. 检查 8000（后端）和 5173（前端）是否已在运行；已在运行就直接复用。
2. 需要启动后端时，先执行 `python -m alembic upgrade head`，迁移失败则不启动后端。
3. 没有运行就分别启动后端和前端。
4. 等待两个服务就绪，然后打开 `http://127.0.0.1:5173`。

日志在 `_local/launcher/`：

- `backend.out.log`、`backend.err.log`
- `frontend.out.log`、`frontend.err.log`

关闭启动窗口不会停止服务。Linux 与 macOS 没有这个批处理文件，按 [部署与数据准备 §2、§4](交付/部署与数据准备.md) 的命令手动启动。

## 第一次进入

还没有数据集时，身份页的教师按钮显示「以教师身份进入（先导入数据）」。进入后到「数据管理」→「数据集」上传六张 CSV，导入方式选「新建独立数据系列」。任务链跑完后才能看到班级、学情与方案，也才能做导出预检。六张表的字段口径与独立评测数据清单见 [部署与数据准备 §6、§7](交付/部署与数据准备.md)。

## 停止

双击 `停止湛知.bat`。它只停止占用 8000/5173 且命令行属于本项目的进程；其他程序占用端口时不会误杀，并会提示是哪个程序占用。

## 常见问题

- 启动器提示找不到 Python 环境：先在仓库根目录执行 `uv sync --locked`。
- 启动器提示数据库迁移失败：看 `_local/launcher/backend.err.log`，先解决迁移错误；空库不会自动建表。
- 启动器提示端口被其他程序占用：先关掉占用程序，或改端口后自行启动。
- 页面能开但模型不可用：在教师端「数据管理」→「模型与外发授权」检查配置；远端模型还需要显式授权外发。
- 页面能开但数据全报错：先访问 `http://127.0.0.1:8000/api/v1/health`，确认后端在运行、`database_ok` 为 `true`。
- 前端起不来：在 `frontend` 目录执行 `npm install`，然后重试。

模型密钥等设置保存在本机 `data/model-settings.json` 或 `.env`，不随仓库分发。
