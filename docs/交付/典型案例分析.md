# 典型案例分析

依据：`3_典型案例说明.docx`。  
正式展示对象为赛题数据 D01—D40，本文件选取 D01、D14、D03 三名学生，覆盖“部分得分、表现较好、记录不足”三种类型，并比较 DC01、DC02 两个模拟班。

## 来源标注说明

本文把“系统固定代码算出来的内容”和“模型在提示词规则下调用 API 生成的内容”分开标注，避免把案例说明文字误说成模型自动生成。

| 标注 | 含义 |
|---|---|
| 【规则计算】 | 固定代码根据原始数据、正式指标和阈值计算，结果可复现 |
| 【数据库原文】 | 来自赛方作答记录、评分点或题目原文，未经改写 |
| 【模型生成】 | 在固定提示词、结构化输出和证据回查规则下，调用模型 API 生成；只解释原因，不改分数 |
| 【规则判定 + 案例说明】 | 判断由规则给出，文字是参赛团队的案例说明 |
| 【案例说明】 | 参赛团队为展示而写的叙述、比较和教学建议，不是系统真值，也不是标准答案 |

这里没有标准答案。赛题允许多种合理分析；本文的结论、教学建议和班级比较属于案例说明，不是官方答案，也不替代教师判断。

本文件涉及的具体来源：

- 指标、分子分母、有效题数、满分比例、证据是否充分、掌握状态：固定代码计算。
- 学生过程、最终作答、评分点、题目编号：数据库和原始记录。
- D01 的 T01I1、T02I1 具体错因解释：模型 API 生成，带原文回查和限制说明。
- D14、D03 没有可用的模型诊断明细，其判断主要由规则指标和案例说明得出。
- 方案任务组、材料、策略：规则规划器生成；部分方案另经模型复核。
- 微课堂正文：按版本分别标记为 `model` 或 `rule`，不能笼统说全部由模型生成。
- 本文的教学建议和班级比较结论：案例说明，不是标准答案。

## 一、D01：部分得分，两个具体动作不稳

### 1. 答题分析

D01 在 N01 有 12 条作答记录，覆盖 5 个观察指标。

【规则计算】指标、有效题数和证据判断如下：

| 指标 | 得分 | 有效题数 | 判断 |
|---|---:|---:|---|
| T01I1 表示数量关系并代入求值 | 1/5，0.20 | 3 | 证据充分，需要练习 |
| T02I1 运用等式性质解一元一次方程 | 5/9，0.56 | 5 | 证据充分，需要练习 |
| T01I2 整式化简 | 2/3，0.67 | 1 | 证据不足 |
| T01I3 倍数关系与解释 | 4/6，0.67 | 2 | 证据不足 |
| T02I3 方程应用 | 1/1，1.00 | 1 | 证据不足 |

具体作答【数据库原文】：

- Q014 / DR0005 / T01I1，0/3。
  - 学生过程：`女生2(x-3)=2x-6`。
  - 学生答案：`3x-6人`。
  - 关键错误：把“女生人数比男生的 2 倍少 3 人”写成 `2(x-3)`，先减 3 再乘 2；正确关系应为 `2x-3`。

- Q022 / DR0007 / T02I1，1/3。
  - 学生过程：`3x-2x=5-6`。
  - 学生答案：`x=-1`。
  - 关键错误：把左边的 `-6` 移到右边时没有变号，应写 `5+6`，正确结果为 `x=11`。

- Q015 / DR0001 / T01I2，2/3。
  - 过程：`1. 原式=6a-3b-2a-4b。2. =4a-7b。`
  - 答案：`4a+7b`。
  - 过程和答案的 b 项符号不一致，可能是符号错误，也可能是誊写问题；只有 1 道有效题。

- Q011 / DR0012 / T01I3，2/3。
  - 过程：`(n-1)+n+(n+1)`，化简到 `3n`。
  - 答案：`3n`。
  - 没有说明“3n 是 3 的倍数”；可能是漏写结论，也可能是不理解如何解释，证据只有 2 题。

### 2. 学情诊断

D01 不是整章薄弱，而是两个具体动作不稳。

【模型生成】第一，文字关系转代数式。T01I1 的 0.20（1/5）不是单纯计算错误，而是在“少 3”应该放在括号外这件事上出了问题。Q014 的过程和答案都指向同一个错误方向。这段具体错因解释来自模型 API；分数、有效题数和证据状态来自规则计算。

【模型生成】第二，移项变号。T02I1 的 0.56（5/9）说明基础解方程并非完全不会，但 Q022 的过程显示移项规则还没有稳定执行。这段具体错因解释同样来自模型 API，模型只解释原因，不改分数。

【规则判定 + 案例说明】其余三个指标暂不下结论：

- T01I2 只有 1 道有效题，过程和答案不一致，无法区分符号错误与誊写错误。
- T01I3 只有 2 道有效题，学生只写到 `3n`，没有解释倍数关系。
- T02I3 只有 1 题全对，不能据此判定掌握。

需要进一步观察的环节【案例说明】：

- 学生能否在动笔前先写出“男生 x 人，女生比男生的 2 倍少 3 人”对应的关系式。
- 学生移项时是否主动标记“变号”。
- T01I2、T01I3 的错是概念问题还是表达遗漏，需要更多同类型题和口头解释。

### 3. 教学建议

【案例说明】实施顺序：

1. 先做 Q006、Q007，练“文字关系先转成代数式，再代入”。
2. 再做 Q023、Q026，练“移项变号并验算”。
3. 两组各配一份微课堂，分别讲“少 3 放在括号外”和“移项要变号”。

分步提示：

- 第一层：提醒“先找谁比谁多、谁比谁少，再决定括号放在哪里”。
- 第二层：让学生自己写出“男生人数 × 2 − 3”，不要直接给最终式子。
- 第三层：如果仍然写错，给一个同类但数字更小的例子，让学生比较两种写法。

后续观察点：

- Q006、Q007 的过程是否先出现 `2x-3`，而不是 `2(x-3)`。
- Q023、Q026 是否主动把 `-6` 写成 `+6`，并做验算。
- 如果仍然先写 `2(x-3)`，下一轮退回前置支持，而不是继续加题量。

## 二、D14：表现较好，用变式和迁移而不是重复刷题

### 1. 答题分析

D14 在 N01 的表现明显高于 D01。

【规则计算】指标、有效题数和证据判断如下：

| 指标 | 得分 | 有效题数 | 判断 |
|---|---:|---:|---|
| T01I2 整式化简 | 5/5，1.00 | 3 | 证据充分，表现较好 |
| T02I1 运用等式性质解一元一次方程 | 10/11，0.91 | 7 | 证据充分，表现较好 |
| T01I1 表示数量关系并代入求值 | 1/1，1.00 | 1 | 证据不足 |
| T01I3 倍数关系与解释 | 3/3，1.00 | 1 | 证据不足 |

具体作答【数据库原文】：

- Q011 / DR0298 / T01I2，3/3。
  - 过程：`(n-1)+n+(n+1)`，化简到 `3n`。
  - 答案：`3n，是3的倍数`。
  - 不仅算对，还补充了“因为 n 是整数，所以 3n 是 3 的倍数”，解释完整。

- Q022 / DR0297 / T02I1，3/3。
  - 过程：`3x-6=2x+5`，`3x-2x=5+6`，`x=11`，并验算。
  - 移项变号、合并同类项、验算都正确。

D14 也有少量失分，例如 Q026 的 0/1，但不影响“整体表现较好”的判断；T01I1、T01I3 只有 1 道有效题，不能因为全对就说已经掌握。

### 2. 学情诊断

【规则判定 + 案例说明】D14 的强项是“过程完整、会验算、能解释”。

T01I2 和 T02I1 都有足够题量，且得分率高，可以判断为 observed_strength。这里的 `observed_strength` 来自固定代码的指标与证据阈值判断，不是模型生成的评价。

但要注意：

- T01I1、T01I3 的证据只有 1 道题，不能把 1/1、3/3 当成“已经掌握”。
- 表现较好不等于不需要学习；下一步应该做变式、迁移和解释，避免重复做同类题。

需要进一步观察的环节【案例说明】：

- 换一个情境后，是否还能保持同样的过程完整性。
- 能否把“为什么这样移项”“为什么 3n 是 3 的倍数”讲给同学听。
- 遇到干扰信息或更复杂数量关系时，是否仍然先写关系式。

### 3. 教学建议

【案例说明】实施顺序：

1. 先用一道变式题检验 T02I1 的迁移，不重复原题。
2. 再用一道需要解释“为什么”的题检验 T01I2，不只看答案。
3. 把 T01I1、T01I3 作为观察项，补 2—3 道不同情境题，不急于判掌握。

分步提示：

- 第一层：提示“换一个情境，先找数量关系，再动笔”。
- 第二层：如果卡住，提示“先写已知，再写关系，再代入”。
- 第三层：让学生比较两种解法的过程，不给最终答案。

后续观察点：

- 变式题是否仍然先写关系式、再计算。
- 是否能解释每一步的依据，而不是只报结果。
- 如果变式题失分，说明迁移还不稳，应补“不同情境下的关系转化”，而不是加同类题量。

## 三、D03：记录不足，先补观察，不硬下结论

### 1. 答题分析

D03 在 N01 的记录覆盖不完整。

【规则计算】指标、有效题数和证据判断如下：

| 指标 | 得分 | 有效题数 | 判断 |
|---|---:|---:|---|
| T01I2 整式化简 | 3/5，0.60 | 3 | 证据充分，需要练习 |
| T01I1 表示数量关系并代入求值 | 0/4，0.00 | 2 | 证据不足 |
| T01I3 倍数关系与解释 | 0/3，0.00 | 1 | 证据不足 |
| T02I1 运用等式性质解一元一次方程 | 1/6，0.17 | 2 | 证据不足 |

具体作答【数据库原文】：

- Q009 / DR0052 / T01I2，3/3。
  - 过程：`6x-2-x-4`，`(6x-x)+(-2-4)`，`5x-6`。
  - 合并同类项和符号处理正确。

- Q025 / DR0058 / 方程，1/3。
  - 过程：`3(x-1)+2(x+1)=24`，但下一步写成 `3x-1+2x+1=24`，去括号时符号和分配律出错。
  - 最终 `x=24/5`，与正确结果不一致。

- Q014 / DR0057，0/3。
  - 过程：`女生2(x-3)=2x-6`，`x+2x-6=3x-6`。
  - 与 D01 类似，都是把“少 3”放进了括号。

D03 的问题不是“没有错误”，而是“错误出现了，但每个指标的题量不够，不能把某一次错误直接判成稳定薄弱”。

### 2. 学情诊断

【规则判定 + 案例说明】T01I2 有 3 道有效题，3/5，可以判断需要练习；具体错误集中在去括号、分配律和符号处理。

T01I1、T01I3、T02I1 的题量只有 1—2 道，虽然出现了 0 分或低分，但固定代码给出的证据状态是 insufficient，不能下“稳定薄弱”的结论。

正确说法：

> 这几项出现了值得关注的错误信号，但记录量不够，先补观察，不把“没有记录”或“少量错误”直接解释为“没有掌握”。

需要进一步观察的环节【案例说明】：

- 去括号时是否逐项分配，尤其是负号和括号前系数。
- 文字关系转代数式是否稳定。
- 方程移项和验算是否形成习惯。

### 3. 教学建议

【案例说明】实施顺序：

1. 先用 2—3 道去括号小题确认 T01I2 的错误是否稳定。
2. 再用 2 道“文字关系转代数式”题补 T01I1 的证据。
3. 方程部分先补 2 道移项和验算题，不急着加难度。

分步提示：

- 第一层：提示“括号前有系数，每一项都要乘”。
- 第二层：让学生把去括号后的每一步写出来，再合并。
- 第三层：给一个同类小题对照，让学生自己发现漏乘或符号错误，不直接给答案。

后续观察点：

- 去括号是否逐项乘到。
- 移项是否变号并验算。
- 补完题后，T01I1、T01I3、T02I1 是否达到 3 道有效题；达到后再判断掌握状态。

## 四、DC01 与 DC02 的班级对比

【规则计算】两个班在 N01 的得分率如下，分子分母来自正式指标，班级人数来自名册：

| 指标 | DC01（21 人） | DC02（19 人） | 差异 |
|---|---:|---:|---|
| T01I1 表示数量关系并代入求值 | 44/87，0.51 | 31/64，0.48 | 两个班都偏弱，DC01 略高 |
| T01I2 整式化简 | 69/101，0.68 | 61/93，0.66 | 接近 |
| T01I3 倍数关系与解释 | 23/45，0.51 | 23/42，0.55 | 接近，但证据不足 |
| T02I1 运用等式性质解一元一次方程 | 65/102，0.64 | 33/76，0.43 | DC02 明显更低 |
| T02I3 方程应用 | 6/10，0.60 | 3/7，0.43 | 题量少，暂不下结论 |

【案例说明】可以读出的结论：

1. 两个班的共同弱点是 T01I1，文字关系转代数式都需要补。
2. DC02 在 T02I1 上明显低于 DC01，差异不在“会不会算”，更像移项、等式性质应用不稳定。
3. T01I3、T02I3 的题量不足，不能拿百分比直接比较，应该先补观察。
4. 教学安排上，两个班都需要 T01I1 的共性练习；DC02 额外需要 T02I1 的移项变号专项，DC01 可以把重点放在变式和解释。

## 五、案例使用说明

- 三份案例分别对应“部分得分、表现较好、记录不足”，但都不是标签化评价。
- 每份案例都区分了“观察到的作答”“推断的原因”“还不能确定的环节”。
- 教学建议都落到具体题目、顺序、提示层级和后续观察点，不直接给答案。
- 班级对比先看共同弱点，再看差异；题量不足的指标不做强比较。
