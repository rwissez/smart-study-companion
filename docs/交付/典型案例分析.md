依据：`3_典型案例说明.docx`。  
数据：D01、D14、D03，节点 N01；班级 DC01、DC02。  
本文展示算法链路，不展示团队整理的标准答案。

## 阅读方式

每个案例分两段：

1. **规则处理输入**：固定代码从原始数据算出的指标、证据状态、作答记录和方案。模型只能读这些结果，不能自己改分数。
2. **未审核 AI 输出**：模型在固定提示词下调用的真实返回，原文保留，未做人工润色。

团队只在最后写“审阅注记”，指出哪些地方需要回查，不把审阅注记混进 AI 原文。

- `【规则处理输入】`：固定代码计算，结果可复现。
- `【AI 未审核输出】`：模型 API 实际返回，未审核。
- `【审阅注记】`：团队对模型输出的事实核对，不是标准答案。

这里没有标准答案。赛题允许多种合理分析；AI 输出和审阅注记都是候选分析，不替代教师判断。
