## 3. 排版注意事项

1. 表格宽度：第 2.2、2.5、3.1、3.5、4.2、4.5 的表格列多，字号可降到 10pt，禁止压缩到 8pt 以下；单元格换行保持可读。
2. 表格跨页时重复表头，避免评委读到断行。
3. 第 2.1 节的架构图现在是等宽文字流程图，入稿时建议改绘为矢量图（Visio / draw.io / Mermaid 导出 SVG），保持同样分层顺序。
4. 代码与字段名用等宽字体，中文正文用黑体或宋体，全文统一。
5. 摘要控制在 250 字以内，当前 217 字，不要再加。
6. 页码从第 1 页起编；封面信息与摘要同在第 1 页，不单独占页，因此没有“封面不计页”的问题。
