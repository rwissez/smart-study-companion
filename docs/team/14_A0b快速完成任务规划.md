新建`src/study_companion/config.py`：

```python
class Settings(BaseSettings):

    database_url: str = "sqlite:///./data/app.sqlite3"
```

### WP2 数据库层（A，2h）

目录`src/study_companion/db/`：`base.py`（DeclarativeBase）、`engine.py`、`session.py`、`models.py`。

`engine.py`用`sqlalchemy.event.listens_for(Engine, "connect")`对每个连接执行：

```sql
PRAGMA foreign_keys=ON;
PRAGMA journal_mode=WAL;
PRAGMA busy_timeout=5000;
```

**A0-b只建12张表**，不建11第三节的全部20张：

| 建 | datasets、source_rows、students、nodes、catalogs、indicators、materials、answer_events、quality_issues、analysis_runs、analysis_results、demo_sessions |
|---|---|
| 推迟到A1 | recommendations、recommendation_revisions、conversations、messages、tool_calls、jobs、idempotency_keys、exports |

理由：这12张覆盖"导入—目录—分析—会话"竖线，是B/C/D立刻需要的；后8张服务建议修订、对话和队列，属于P1/P2功能，提前建会拖慢A0且很可能在A1返工。**迁移分两个文件**：`0001_initial`（本次12张），`0002_agent_and_recommendations`（A1）。alembic支持增量，不是技术债。

### WP3 HTTP骨架与响应包络（A，1.5h）

目录`src/study_companion/api/`：

| 文件 | 内容 |
|---|---|
| `envelope.py` | `success(data, warnings)`、`failure(code, message, details)`，统一填`schema_version="1.0"`和`request_id` |
| `errors.py` | `DomainError`→HTTP映射；`RequestValidationError`→400 `VALIDATION_ERROR`；兜底500不泄露堆栈和绝对路径 |
| `deps.py` | `get_db`（每请求独立Session，用完即关）、`get_scope`（从Authorization解析会话，返回`SessionScope`） |
| `routes/health.py` | `GET /api/v1/health` 返回app版本、schema_version、db连通性、`model_configured: bool` |
| `routes/demo_sessions.py` | `POST /api/v1/demo-sessions`、`GET /api/v1/datasets` |
| `middleware.py` | 为每个请求生成`request_id`（优先取`X-Request-ID`），放入contextvar供envelope使用 |

`main.py`暴露`create_app()`和模块级`app`。CORS只允许`http://127.0.0.1:5173`和`http://localhost:5173`。`DEMO_MODE=false`时`/api/v1/demo-sessions`直接404，不是403——不暴露演示端点的存在。

demo-session的最小规则（11第六节）：teacher可不带`dataset_id`创建bootstrap会话，`scope.capabilities`只含`list_datasets`、`import_dataset`、`select_dataset`；student必须带已存在的`dataset_id`和`student_id`，服务端校验学生属于该数据集，否则404。token用`secrets.token_urlsafe(32)`，库里只存`sha256`，明文只在响应里返回一次。

交付检查：`tests/api/test_health.py`、`tests/api/test_demo_sessions.py`——包络字段齐全；student带不存在的student_id返回404且错误体符合08；越权访问返回403。

### WP4 模型适配器骨架（A，0.5h）

**签名改为同步**（见第六节修订1）。`src/study_companion/agent/`：

```python
# agent/types.py
@dataclass(frozen=True)
class ToolCall:   call_id: str; name: str; arguments: dict
@dataclass(frozen=True)
class Usage:      prompt_tokens: int | None; completion_tokens: int | None
@dataclass(frozen=True)
class ModelTurn:  text: str | None; tool_calls: list[ToolCall]; usage: Usage | None

# agent/provider.py
class ModelProvider(Protocol):
    name: str
    def generate(self, messages: list[dict], tools: list[dict] | None = None,
                 response_schema: dict | None = None) -> ModelTurn: ...

# agent/providers/unconfigured.py
class UnconfiguredProvider:
    name = "unconfigured"
    def generate(self, *a, **k) -> ModelTurn:
        raise DomainError("MODEL_NOT_CONFIGURED", "模型服务尚未配置")

# agent/factory.py
def build_provider(settings: Settings) -> ModelProvider: ...
```

## 六 对11统一实施规范的修订意见

以下四条需要在A0-b编码前确认，否则代码一写就与规范冲突：

**修订1（必须）：`ModelProvider.generate`由async改为同步。** 11第11行规定数据库用同步Session，第148行规定后台任务跑在worker线程。若provider是async，worker线程内需要自建事件循环，与同步Session混用会出现嵌套和连接归属问题。单进程本地应用用`httpx.Client`同步调用更简单，且工具执行本身是同步的数据库读取。改动范围只有11第142行。

**修订2（必须）：A0-b只建12张表，分两个迁移。** 见WP2。11第三节的20张表作为最终目标不变。

**修订3（建议）：`.env.example`增加`MODEL_TIMEOUT_SECONDS=45`，并把四项模型配置的说明改为"默认未配置，可选接入"。** 11第162行"模型四项保持空值"保留（值确实为空），但不再表述为项目范围上的"不接入"。

**修订4（建议）：A0-b不实现`jobs/`队列，接口同步返回。** 11第148行的`queue.Queue`+worker线程推迟到A1的P2。A0阶段没有任何耗时操作（分析在A1、模型在A1），提前建队列只增加重启恢复语义的实现和测试成本。13第4.5节已把队列列为P2，本条只是与11对齐。
