# D工作指南

## 开工前必须执行的技术基线

先读11，与A协作在A0分支初始化frontend，统一React/TypeScript/Vite/npm、React Router、TanStack Query、Recharts、CSS Modules及锁文件。A0合入后才独立开发双端。前端只经src/api封装访问相对/api/v1地址，业务类型由OpenAPI生成，不能手写第二套契约或另建后端。保持视觉自由，功能路由按11。验收typecheck、test、build及关键Playwright路径，命令见11。

你的目标是把结论、证据和教学动作展示清楚，并让最终提交物能打开、能复核。

## 双端功能范围

教师端：按班级分类查看名册与概览；选择学生查看学习画像和作答证据；查看课程要求、必要联系及材料出处；查看教学建议并调整材料、顺序、提示或说明，填写理由并保留原版；围绕选中班级/学生对话追问；查看数据质量及导出成果。

学生端：查看自己的学习画像、需要关注的内容与证据限制；查看学习安排、具体材料及分步提示；围绕自己的学习任务对话。学生端不返回其他学生明细、教师审核信息或参考答案字段。画像仅指学情摘要，不是人格测评。

## 视觉与交互自由度

教师端强调清晰比较与依据追溯，学生端强调易理解、行动引导与友好反馈。布局、色彩、字体、图形、动效和交互细节由D自主设计，不指定固定模板。两端保持产品识别一致；不得为美观填造缺失指标、掌握分数或学习趋势。

基础版使用明确标记的模拟身份切换，非生产账号系统。切换角色、学生、班级或数据运行时清除旧展示并建立对应会话；后台按会话限制数据，不能仅靠前端隐藏。模型API默认未配置、可选接入，未配置时对话区显示“模型服务尚未配置”，不返回假模型回答。页面其余分析与材料功能可独立工作。

## 按顺序执行

1. 阅读08，使用A提供的示例搭页面，示例数据显著标记，不作为实际学生结论。
2. 实现上述学生端与教师端、班级分类、学习画像、对话及依据查看，先保证核心路径完整，再自由完善视觉。
3. 所有图表展示样本数、节点与指标口径。null显示无可用结果，不画成0；证据不足使用文字说明，不能简单涂成低分红色。
4. 点击诊断可以查看记录和评分点，点击建议可以查看材料与理由。原始文本按文本渲染，不能执行其中HTML或脚本。
5. 接入真实服务，处理加载、失败、空数据、隔离记录、模型降级和运行版本。切换数据或运行后清除旧展示。
6. 通过服务导出成果包，核对schema、字段说明、输入输出样例、质量报告和操作说明。各模块负责人确认内容，D确认目录及文件可读。
7. 按脚本录制不超过5分钟视频；准备现场演示和历史结果备份，并明确历史结果身份。

## 视频建议顺序

问题与范围20秒，课程材料40秒，导入及质量检查40秒，三类学生案例120秒，班级分析40秒，导出与限制20秒。总计约280秒，保留余量。具体镜头按真实功能调整，不录尚未实现的功能。

## 验收

新增展示：按09显示智能体实际调用的工具名称、完成状态、相关证据及结果限制；不展示或编造模型隐藏推理。按钮流程与自然语言入口共用分析结果。API未配置时明确显示未接入，不能把历史或示例回复冒充实时生成。

在演示电脑上完整运行；三类案例均可查看依据；无记录学生仍可选择；后台失败不会显示旧成功结果；长文本可读；导出包由另一队员解压并按说明复核。界面显示的分子分母应与B输出一致。

双端验收：教师可按班找人、看画像、查看建议、调整并回看理由；学生只看自己的学情、安排及提示；对话上下文不串学生，服务端响应不包含被隐藏的其他学生数据或答案字段。

## 可交给Codex的起始任务

阅读00、01、02、08、09、10及D指南。实现学生端、教师端、班级分类、学习画像、对话和依据查看，视觉及交互由你设计。只修改frontend及相关测试/说明，按共享示例开发再接真实接口，不在前端重算统计或编造画像。模型API保持空白并显示未配置。角色裁剪与教师调整保存由A后台配合；接口变更交A协调。
