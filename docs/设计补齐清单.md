## 需要模型、本清单不含

1. 教材页面语义提取、公式符号核对、知识点语义去重与关系判断。
2. 解答题按评分点逐项评分。
3. 微课堂推导/对照/数轴等教学内容生成。
4. C 的独立模型复核与一次修复。
5. Agent 的教学解释、事实组织与回答审查。
6. 难度评估中的模型判定（规则部分已列在 C）。
