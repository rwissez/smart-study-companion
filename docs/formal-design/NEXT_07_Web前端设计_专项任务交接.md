| 页面或流程 | 必须消费的行为与契约 |
|---|---|

| 成果导出 | 现有数据管理选择授权范围及典型学生，POST 冻结正式结果，显示合规失败原因与可采取措施；ready 后下载同一 export_id。模板示例不足与缺失必要结果区别显示。 |
| 证据和历史 | EvidenceResolver 精确版本、课堂/学生权限和答案阶段裁剪。同一视图能显示原生成 B2、当前 B3、C2 的已复查适用范围及待复查/暂停原因。 |

| 学生计划和历史 | 01 活动 start/complete、题目 attempts/submit/hints、微课堂 complete，重试同业务键。预览与“完成”有明确可操作状态，阅读只作历史，不显示虚假评分。 |
| 微课堂与 Agent | 04 六种基础安全组件及合法降级。业务页面携带活动/计划/内容版本；共用帮助保护、学生受助确认、真实帮助记录，避免直接渲染 HTML 或任意代码。 |
| 角色与演示 | 继承已确认教师四、学生三个一级入口，真/演示明确标志并隔离，授权错误不得静默改数据源。 |
