## 1. 数据、源码和职责

C 接收授权绑定的 family/dataset/run/student/node、正式 Catalog/KnowledgeIndex、B StudentResult 与 LearningEvent 高水位、当前正式计划及教师意图。输出方案候选、审核、发布版本、后续差异、教师介入记录、质量报告。A 提供课程范围、核验关系、正式题目及教材关联；B 提供证据、掌握状态、诊断、评分及学习效果；Agent 提交受控意图及记录实际帮助；Web 读服务端角色投影、渲染微课堂、提供正式教师编辑界面；DB 提供事务和历史。C 只计算教学排序和安排，原 B 结果保持不可变。

赛方六 CSV 读取结果为 9 指标、40 名模拟学生（21/19）、65 材料（54 题含 18 解答题、3 学习卡、8 教材登记）、2 节点、806 作答行。按事件最高修订初步计 799 个事件（790 已评分、4 待评分、5 未作答），536 个缺解答过程，尚须由 B 做完整合法性过滤。Excel 索引 7 张表，相关表行数与 CSV 一致。N01 仅 T01 和 T02 一元一次方程，节点列列出 Q001—027；N02 含 T01、T02 方程组、T03，列出 Q001—017、Q028—054。服务端同时校验节点可用题目及已教的细粒度范围，主题名相同不能替代此检查。不同节点同题集合也不能自行得出可比结论。无记录、未作答、待评分、冲突、答错分别保留。官方历史无帮助字段，独立性 unknown。独立评测尚未提供，禁止预设学生或题号。正式展示由真实结果选三名，覆盖两个班级分析。

## 2. 一次生成的边界

授权及快照锁定 → 教学需求聚合 → 策略/目标 DAG → 候选资格与评分 → 规则基线 → 模型调度和组件生成 → 硬校验 → 独立审核及有限修复 → CAS 发布 → 学习事件追加 → B 正式更新 → 有条件重新规划。每次 plan job 保存 input fingerprint，包含授权范围、A/B 指针、base_plan_version、事件 cutoff、规则/配置/提示/模板版本。DAG、候选表、逐项得分、排除码、引用、审查证据与发布原因可追溯。教师直接编辑走独立发布路径（§8）。

## 3. 教学目标与策略决策

### 3.1 聚合、启动与退出

每个已教 kp 建需求，不能定位 kp 时只建 indicator 级补证或教师处置；仅依赖 A 正式 primary 关联选证据题，若无足够细粒度覆盖则显示指标层限制。只读与本快照匹配的正式 StrategySignal、Finding、DiagnosticDetail、ProgressComparison。signal 去重按 signal_id，计次数按真实不同事件/题及 B 版本，不能以多个引用给同次作答加权。相同 kp 有冲突状态时保留引用和冲突标志，采用 B 结论；同范围同时有相斥的有效结论且 B 无明确裁决时进入补证/人工，C 不选更方便的结论。无当前正式 B 指针先请求正常分析流程，展示旧计划可用范围。

| 策略 | 启动谓词（作用于目标） | 退出或转向 |
|---|---|---|
| collect_evidence | evidence_gap 或 evidence_status=insufficient/conflicting，或没有可验证的细粒度诊断但范围可用。冲突且无合格独立题则转人工 | B 更新为 sufficient 后重选；证据仍不足按 §7，禁止升级成薄弱 |
| prerequisite_support | 当前目标受阻，A 有已核验必要前置路径且路径上有 B 充分证据的实际弱点。仅有 prerequisite_gap 信号不够 | 前置由 B 证实改善到 developing 或以上且对应具体障碍解除，释放原目标；若有新可靠弱点则继续排最先阻塞点 |
| error_correction | sufficient 且 concrete_error 有 B 已核验的具体错误/证据，错误当前相关，无更上游阻塞 | 当前错误消失且有可比独立证据，转巩固或结束；重复无改善依 §7 |
| consolidation | sufficient，且存在 unstable_performance、无已确认根因/阻塞的 needs_support/developing，或纠错后 B 仍确认不稳定 | 可比独立证据稳定且 B transfer_ready 可迁移；否则结束或按 §7 |
| transfer | sufficient、transfer_ready、B 对应 mastered 且无冲突、无目标现存阻塞 | 一轮已验证迁移表现后结束；新的可比失败由 B 定位后转补证/纠错等 |
| teacher_intervention | teacher_attention 有可核验证据且限制无法自动解决，或无效/证据不足/材料约束达到 §7，或明确安全人工处置 | 教师记录处理结果并显式关闭或最新 B 证实问题解决且未被教师锁定；按具体问题保持开放 |

主策略优先级为必须人工阻断 > 补证 > 必要前置 > 纠错 > 巩固 > 迁移。教师介入可与其他目标并行。同目标主策略唯一。允许前置带少量纠错或巩固（只服务前置目标），纠错带巩固，巩固带短讲解与独立检查；证据组不与会教待测目标的活动同组，迁移组先独立应用，教师介入组由教师安排。每组记录 goal、目标 kp、预计表现、主辅策略各自理由、证据，活动另记录目的与预期。教师有明细含限制，学生投影使用同一事实与安全引用。

### 3.2 排序与前置

E：P=100×(.24I+.28N+.16R+.20D+.12U)。I=配置中的正式 kp 权重（默认 .6，节点核心可 .9）；N 使用 B 已确定状态映射 needs_support=1、developing=.65、mastered=.15，其余未知取 .45 作补证价值代理，needs_support 的强度从不用于未知，transfer_ready 目标取 .35；R 为 sufficient=1、insufficient=.45、conflicting=.25（人工明确安全类单列，不参加普通评分）；D=min(1,被该点实际阻塞的可用候选目标数/2)；U 最新相同范围可比 ineffective=1、partial=.65、improved=.2、insufficient 或无比较=.5。公式只用于排序，保留每项来源；同分按等待轮数降序、kp/indicator 键升序。等待三轮仍合格时，在不违反依赖的前提下可占一个普通目标席位；同一轮最多两个独立目标，前置替代其后继席位。

从目标沿 A 已核验 prerequisite 逆向遍历（P：最多3边、20节点，按 ID 稳定遍历）。仅收录已教、scope 适用且该关系可阻塞当前解题路径的前置，A 无路径级用途信息时须有 B 的错误步骤或 prerequisite_gap 引到该前置才算必要。寻找已确认 needs_support/developing 且与阻塞证据相符的点，忽略稳定点；未知前置需要补证而非补课。对必要子图拓扑排序，保留原目标为 deferred；存在环、跨范围依赖或超预算时标阻塞并报质量，禁止自行降级关系。每个可运行前置组先准备支持内容、适配题、独立检查，只有 B 新正式版本和门槛通过才解锁后继。

合成算例：去括号目标 I=.9,N=1,R=1,D=.5,U=.65，P=83.4；未知不等式目标 I=.6,N=.45,R=.45,D=0,U=.5，P=40.2。若去括号的负数乘法前置由 A/B 双证明确认为阻塞，先排负数乘法组，原目标保留待处理；若 B 未确认前置薄弱则不能自动补习。N01 不等式会在进入公式前被排除。

## 4. 精准选题与编排

### 4.1 候选资格与元数据

检索索引键 (catalog_version,knowledge_version,node_id,kp_id,role,material_kind)。先交集正式 Catalog、节点已教范围及题目 allowlist、A 核验 annotation（question→kp 与 role），校验材料版本、有效状态、原题和答案可供内部核验。所有材料关联须授权。正式练习不得使用生成例题；缺关联只可由 A 核验后再入池。学习卡使用有登记的 card；教材使用 A 已核验术语与片段，在课程范围内并通过版权授权。查询预算每目标最多20题、8支持素材，按初始评分再截断，保留原始候选数与拒绝原因。旧题意及学生原文只在必要且授权时进入模型上下文。

DifficultyProfile=(material_id,catalog_version,knowledge_version,source_hash,features,level?,review_status,review_refs,rule_version,observed_stats?)，level=basic/medium/advanced，review_status=unknown/candidate/verified。features=(steps:1..8,primary_kp_count:1..8,has_modeling:bool,representation_switch:bool,case_split:bool)。E：complexity=min(4,steps-1)+min(2,primary_kp_count-1)+2×has_modeling+representation_switch+case_split，0—2 基本，3—5 中等，6以上进阶。steps 为数学关键操作数，跨步骤重复书写只计一次。按题独立抽取，对可解析题以确定性结构复核，否则独立模型检查关键步骤和类别，分歧由教师审核或保持 candidate。群体作答观测只作复核触发：同节点有效 N≥20 且同等评分口径，保留实际 n/有效正确人次以及区间；若基本题正确率 <.30 或进阶题 >.85，进入复查，不直接修改数学类别。未知难度有独立状态，可选供普通练习且需要审核，不作为具有难度保证的诊断题。

Fingerprint=(material_id,content_hash,operator_family,method_tags,primary_kp_ids,normalized_shape,step_signature,review_status)。通过受限 AST 消去题目文字语序差异、规范变量角色；另保留保号/开闭/等价规则等关键结构，数字遮罩版用于发现克隆。S=.45×shape_match+.25×Jaccard(method_tags)+.20×Jaccard(primary_kp_ids)+.10×ordered_step_similarity。后者为 LCS/max(len)，空集合相似取0，未知不能视为0相似且可保证不同。S≥.80 视为近变式，整组默认同簇≤2。真同题或等价克隆只允许历史上有明确重练目的的同题活动；组内每个 material 仅一次。错因同型变式需有不同数字以外的一项结构或表示差异，答案保护另按§6作更严格判断。

### 4.2 各策略资格与评分

| 策略 | 候选准入和组合 | 初始题量 |
|---|---|---|
| 补证 | primary、难度已核验且通常基础/中等，题目直接测目标，至少一题能留过程或可靠评分点，独立且尽量未见；诊断期不给预设提示，学生请求帮助时退出独立检查并切换为指导模式，该题不会贡献独立证据 | 2–3 |
| 补前置 | 前置 primary 的基础题优先，必需时先教材/微课堂，再练，再在充分间隔后独立检查；不给后继目标题提前泄题 | 按可用预算 |
| 纠错 | primary 且含 B 已核验错误对应的 A 步骤/评分点/结构；一题确认修正，一题结构变式，必要时隔时重做旧题 | 2–4 |
| 巩固 | primary，基本→中等，至少两个可区分的任务结构；间隔重练或逐步减少可用帮助 | 3–5 |
| 迁移 | 使用主要或核验的 supporting 目标关联，同时须有已教的 primary 组合、具体迁移用途与新表示/场景；辅助关系本身不足以支持诊断 | 1–3 |
| 教师介入 | 记录可行动建议及证据；可先不排学生任务。教师可以按目标补教材/讲解/题 | 无固定 |

选题 E：score=100×(wK K+wE E+wD D+wH H+wV V+wM M)。K=primary 1/supporting .55，E=已核验相同评估步骤1/仅目标机制 .5/无 .0；非纠错若无错误信号用中性 .5。D=符合策略目标难度1/相邻 .6/未知 .3，跨两档0；H 如上；V=有受益的结构变式1/同类但无额外价值 .4/不适用 .5；M 在贪心构造时为 1−max S（首题1），未知 .35。公式按以下权重顺序 [K,E,D,H,V,M]。每步重算 M，同分按 material_id，所有得分精度保留六位后比较。

|---|---:|---:|---:|---:|---:|---:|
| 补证 | .34 | .05 | .20 | .24 | .03 | .14 |
| 补前置 | .32 | .17 | .20 | .15 | .05 | .11 |

| 迁移 | .22 | .05 | .14 | .15 | .22 | .22 |

### 4.3 负担与任务组

P 题估时 basic/medium/advanced=2/4/6 分钟，未知取6，需完整书写额外2（题库有已核验时长可用其 1—12 分钟值），学习卡2、教材片段4、微课堂3—6、整组切换1。默认全轮 20 分钟、最多8个学生活动、两个学习目标；不挤掉进行中任务，剩余预算不足则等后续。节奏为必要前置依赖→有需求才讲→低负担直接练→间隔独立检查或迁移，可按材料和错误调整，禁止仅按题型排序。按候选组的拓扑可行性迭代选入，先删可选讲解/冗余题，再缩量，再延后次目标。只有一题可排时标低覆盖，不能承诺后续 B 能形成充分结论。无合格题而支持材料可靠时允许非评分学习组；无学生可执行内容仅排队/教师处置，不发布假完成活动。每组保存 estimate_minutes、expected_outcome、策略解释、候补/延后原因和完成门槛。教师手动时教学时间警告可确认，字段数量和复杂度资源硬限维持。

### 5.3 调用预算与降级

每次方案最多8次实际请求，含网络重试。计划典型 optimize 1、补查后 optimize 1、write_content 1、review 1、repair 1、复审1，余下给一次短暂错误重试及结构修复之一；合并内容分批须从同一预算扣减。item_features 按题元数据任务预算独立（单题2次含独立复核，网络失败改后续 job）。每次请求默认45秒，总 wall 180秒，超时或限流退避 1–3 秒最多重试一次；非法 JSON 至多一次格式修复计入同一修复额度；语义修复最多一次且必须全量重新硬检/独立审核，预算不足即暂停。search 全 job 最多一次、同目标同范围、≤10增量；程序无该目标即拒绝，从未授权范围一律拒绝。缓存键=(task_key,prompt_version,provider/model_revision,rule/config_hash,snapshot/input_digest,policy_scope_hash)，生成/审核缓存隔离，授权失效立即失效；正式发布审查绑定完整 draft_hash。记录 request_id、真实状态/用量/重试/模型/提示/规则版本、审查输出与失败码，避免在公共日志存题解或学生文本。

授权拒绝、模型缺配置、短暂故障、输出结构错误、语义冲突、无法核验、安全损坏分别记录。失败优先保持仍可靠的正式组。可降级的规则发布只限校验完整的预审模板，模板注册需固定版本/适用策略、确定性数学可验证、预核验提示与受控引用、全六项可程序验证、正式素材有效。模板绑定题目和版本，不能运行时拼未审核内容。默认候选为使用审核过的基础题与预验证提示的巩固或补证、已核验登记片段；其他模型依赖项转人工/暂缓。审核记录为完整规则覆盖及模板版本；模型故障即使规则发布成功也记录 warning。禁止降级绕开安全不确定。恢复模型后按当前依赖新建候选，遵循旧计划与教师保护。


## 6. 三级提示与结构化微课堂

### 6.1 答案保护与提示协议

三级提示限知识回忆、方向、关键未完成步骤。正式题活动保存三条核验文本，每条≤300字；没有适用安全文本时不强造，可使用该题经核验的离线模板，否则暂缓该题。补证/独立迁移的提示仍登记，独立模式下受门控，学生显式转入受助模式后才发放。提示 API 一次只返回授权的下一层，重读原层幂等，禁止跳层取答案。展示帮助前先持久化 help intent，发送成功返回实际事件；若响应失败且暴露无法判定，则 attempt.assistance_status=unknown，不能标独立。提示和 Agent 共用 01 事件账本与披露状态；独立检查下提示 allow_assisted=true 和 Agent assisted-confirm 均调用同一受助转换服务，绑定当前 attempt 和版本，转换本身不计实际帮助。对 Agent 依活动/尝试按相同策略裁剪可见上下文与回复；不向 Agent 的通用历史提供未开放的提示层、参考答案或评分细则。

扫描保护集合为本活动及学生在同课程可访问的尚未完成的正式题，包括后续已排题、可从替换计划进入的进行中题。每次发布/更换后继计划重新核对当前仍能访问的活动，并记录已读微课堂/已发提示的披露指纹。材料和引用展开的安全预览亦参与检查。第一级旧 check_hint 查直接串、规范拼写、选项槽位及长片段。第二级解析归一常数、分数/小数、等式、解集、选项映射和最终答案，匹配“答案槽”与数学等价表达；禁止泄露等价结果或足够唯一确定的流程。数值碰巧重合但出现在无关上下文不能单凭一个 token 判泄露。第三级比较例题与保护题的 AST 形状、变量重命名、数字遮罩、变换序列与最终结论，硬挡同题、轻微改数字/名称的克隆、连起来等价于完整解答的三级提示。S≥.80、表述可推导或关系未知进入独立审核，仍不确定则阻止该内容对学生发布。教师手动可使用确定性可证的模式或已审核对象，超出可证明安全边界的任意文本可保存为草稿，通过更换内容解决，无需等待大模型。引用保存学生安全投影，缓存按角色和活动权限键隔离，暂停中的题也保持保护。

### 6.2 内容、活动和权限

for group in ready_groups:

    order = stable_topological_order(selected, teaching_stage_then_load_then_id)
