## 补充核查结论

- 01 §9 汇齐 02/03/04 的 A/B/C 正式质量报告；03 §12.4 的 B 判定成为班级比较 HTTP 的唯一业务来源。作答分页由完整授权仓储集合提供，通过 EvidenceResolver 查看细节。D 的旧 quality、runs 查询及 Web 两侧比对只作复用依据。
- 01／04／07 的直编仅 preview → publish。旧 publish 布尔字段仅进兼容完整审核，微课堂继续独立读取及完成。教师介入详情和结案复用04对象、证据与06审计，结案不改诊断、成绩或计划。
- 01／06／07 对齐 POST /jobs/{job_id}/retry 的可重试条件、一次额度、原失败关联和重放。06 用根唯一约束抗并发，并与普通自动重试去重键区分。D 现有 Job/GET 与幂等无此语义，待开发。目标验收覆盖同键返回同一子任务、不同键并发只生成一次、原失败不变、过期依赖和无权拦截。
- 00 E-03 采用一次授权后依赖驱动自动推进，03／04／05 标明正式基线 00 v1.3、01 v1.3 及当前审阅增量；不改已确认算法。07 使用 [唯一选定原图](assets/湛知书页新芽徽标.png)。原型只更新图片引用。

新增公开查询路径、分页投影、结案形态、重试持久化约束属于工程契约，待实施；未做运行或并发测试。源码依据沿用 [实际代码核查](实际代码核查.md) 的固定 main/D。尚余问题在 [问题清单](待确认问题.md)。
