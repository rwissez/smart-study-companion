# 湛知代码改造与开发计划

版本 v1.0｜2026-11-27｜实施对象 DSH。业务源为同分支 00—07、[决策 v0.55-draft](智慧学伴总设计——讨论与决策记录_v0.55-draft.md) 及其 v0.54 历史。按用户本轮确认落实 DEV-01—10 与后续细化的一次授权、四工作线、断点续跑和一致性门槛。附件《0809讨论》中的方案、示例和建议秒数用于工程设计，当前对话的确认范围优先。阶段通过条件见 [09](09_测试与验收标准.md)，执行纪律见[仓库根 AGENTS](../../AGENTS.md)。

## 1. 交付边界

交付能从干净目录安装、启动、导入或读取实存成果、运行师生流程并导出正式 ZIP 的本地湛知产品。完整支持 A 知识体系、B 统计/诊断/评分、C 计划/微课堂、Agent 受控真实工具、Web 师生交互、学习反馈及持久化。原方案在新学情下仍适用是正常结果。C-30 三路径、AG-14、数据权限、提示保护、真实和 demo 隔离是交付条件。六个基本微课堂组件必须实现，增强按04优先级。比赛 PDF、视频、答辩 PPT 沿团队现有交付安排。样例、静态原型、模拟模型各保留明确身份。阶段成功以对应快照的验收证据为准。

## 4. 数据库升级与版本边界

保留共同 0001_initial、main 0002_learning_observations、D 0002_local_results/0003_idempotency。先按06建立两头的合并 revision（父为 main 0002 和 D 0003），继而统一表、分批回填；空库和从旧 main/D 升级都须有且仅有一个 head。不得重写已发布迁移或凭空 stamp。先检查 schema 与 revision 和所有数据目录，使用 SQLite backup API 或停写窗口制作整套备份，在隔离副本先试跑；检查 integrity_check、foreign_key_check、新旧行数/摘要、父快照映射、关键历史样本。应用切换后读取正式指针、运行只读回归，失败恢复匹配的 DB/文件/代码版本，保留升级日志。旧未核验记录只作为 legacy history，保留原审阅标签与限制；帮助缺失为 unknown，禁止造 grade 或发布。目录及 A 文件不可变，正式头在 DB，导出读取精确依赖闭包。

跨模块共享边界按01/06：scope 和发布资格在服务端验证，原始内容和历史快照保留；同一族补充保留真实身份、独立评测不拼接。B 先选高水位内最高已登记修订，再判断是否 graded/validated。C2 原依据 B2，针对 B3 的重检为独立记录，保留原依赖。任务执行、审核、发布分列。幂等兼顾请求键与业务唯一键，教师一次手动重试建子任务，原失败仍可读。SQLite 写事务不跨模型调用，发布、事件及 outbox 原子保存，重启可安全续跑。

## 7. 恢复、自动验收与推进

实施时创建仓库的执行状态文件 execution_state.json 和 DEVELOPMENT_PROGRESS.md（开发记录，非 Web 功能）。JSON 存 schema_version、docs_commit、base_sha、current_sha、每任务 status/deps/commit、gate 结果与证据相对路径、next_ready、blockers、updated_at。写临时文件再原子替换。结果状态 pending/running/failed/blocked/passed，测试单独记 not_run/failed/passed/not_applicable 及原因。日志保留真实失败和修复；进度摘要使用模板由实际状态更新，禁止记密钥、题解或赛事原始数据。运行产物路径与提交状态可核对，不把本地 SQLite 或数据包汇入 Git。

DSH 运行循环：读取文档和状态→校验当前 commit、未提交工作与上次证据→选择所有依赖已通过的任务→实现→调用09门槛→记录真实执行日志。普通失败定位，最小修复，再跑失败用例、受影响接口和用例套件；通过才提交阶段检查点并自动进入后续，保留失败记录。重大不可解设计冲突、必需外部依赖或权限阻塞仅冻结影响子图，继续独立工作，最终报告实际 blocker 与证据。外部终止后的重新启动依宿主能力，续跑读取记录重新核验已通过项，不假定有后台常驻进程。

## 8. 部署和最终交付

使用核验过的锁，目标机干净克隆，先用隔离目录执行空库与两旧头升级，再接授权赛事数据。按09健康检查与实际双端运行验证，浏览器构建产物与后端同一 commit。保留 README 的启动方案并更新为可复现的双端操作、.env.example 措施、API/演示切换、数据位置和备份命令。完成真实 A/B/C 可复查并保存到比赛机，三学生及两班材料由教师/团队选取，验收前全链与实际模型执行一次。现场使用预生成的真实正式成果可节省时间，Agent/作答代表流程按实演示。网络故障时可读已存成果、清楚说明在线模型不可用，保留独立的实际验证结果。

交付齐备：最终 commit、锁、启动和迁移说明、真实授权数据处理入口、可用 Web、完整工具及事件、可生成并下载的正式成果包、合成与真实验收记录、三尺寸截图、问题等级和未修复项、备份/恢复演练。按09处理 S0/S1及必需用例。项目启动命令、模型、演示及本地数据责任不得由用户手工拼装。应用发布与 main 合并依09放行及已有远端权限。
