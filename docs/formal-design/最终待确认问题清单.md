# 湛知最终待确认问题清单

版本 v1.0｜2026-11-27。以下为当前文档中仍缺共同决定、且影响相关交付的项目。它们不构成独立开发阶段或全面阻断。DSH 可以启动 P0 与其他已授权工作。

| 编号 | 仍待确认及停止边界 | 已可实施范围 |
|---|---|---|
| F01 | 学生预登录身份选择的受控来源还未冻结。比赛机身份引导要确认如何提供可选择对象和会话，尤其是未登录可见信息；不能把教师名册开放给匿名请求。 | 复用受控本地会话创建及角色投影，准备 UI 和授权测试；只阻断选人入口的现场验收。 |
| F02 | 历史恢复在正式编辑器的 preview/confirm 具体请求字段未统一。若要实现预览后的人工作用，P1 先核对能否由现有04/01签名表达，不能以普通旧 publish 假装确认。 | 已明确的普通编辑、授权 undo、Agent 候选恢复及历史保护可实施；教材、B/C 算法等不依赖。 |
| F03 | 逐人交叉比较在07有入口，01只冻结了班级横向比较。需确认独立学生 compare HTTP 是否为必要交付；若是，冻结精确范围和结果类型。 | 两个授权个人结果读取和 B 范围限制可实施；不得在前端推定可比性、重新计算正式差值。 |
| F04 | 教师系统运行区的公开 Agent 质量聚合及工作流列表细节仍缺公共契约。若最终页面必须提供专用聚合或任意依赖图，需确定必需范围与投影。 | A/B/C 报告、job详情/事件/取消/一次重试和关联 job 可实施；禁止访问内部日志填空。 |
| F05 | 导出 GET 预检响应区分正式 manifest 与缺项的具体判别字段和查询筛选尚未冻结。若展示必须依赖独立预检，P1 限于接口协议补齐。 | 已定 POST 快照、202任务、授权下载和真实缺项提示可开发；GET 不写快照。 |

外部执行条件按实际状态记 blocked，包括赛事原文处理授权、真实模型配置与网络、正式演示机或 UI 审查时间。其真实状态待 DSH 实机查证。独立评测范围和最终提交通知按赛方实际文件核验。已有 Logo 原图，未发现 UI-01—30 独立附录；07 本体与视觉规范足够开始开发，最终视觉仍需截图及人工审查。源页 MIME、微课堂安全索引、未核验难度和指标级材料的可推导约束见[一致性报告](08—09—AGENTS一致性检查报告.md)。
