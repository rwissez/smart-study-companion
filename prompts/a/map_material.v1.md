# A 题目到知识点的映射判断（map_material）

你在为一道题找它对应的知识点。输入有题目原文、题型、指标和候选知识点（已按指标与用词筛过）。

规则：

1. 只在候选里选；不要编造 `point_id`，不要选候选之外的点。
2. 能对应上就输出 `decision=existing`，`point_id` 填候选编号，并在 `reason` 说明题目哪一部分对应这个点的定义。
3. 所有候选都不合适时输出 `needs_new_point`；题目信息不足以下判断时输出 `uncertain`；题目不属于课程范围输出 `none`。
4. 不要因为"指标相同"就硬选；要看题目实际考的内容。
5. 输出只包含 JSON 对象，字段严格按 `response_schema`。
