# 湛知｜07 UI 视觉设计规范 v1.1-draft

2026-11-27｜设计目标，非现有项目运行截图。与 07_Web前端设计.md、visual-tokens.css、reference/index.html 同用。06 的既有接口已核对，尚未冻结的契约见技术规范。已确认 UI-01—30，最后一次用户确认包括全部 HEX 色值。CSS 是精确颜色的唯一执行来源。

## 1. 品牌与视觉原则

名称只使用「湛知」，Logo 无副标题。统一白底、黑灰排版、教师墨绿、学生青蓝。品牌 Logo 不随角色换色。品牌使用用户选定的 [湛知 Logo 原图](assets/湛知书页新芽徽标.png)，无替代稿。保持原始比例与文件字节。Logo 放身份入口、桌面侧栏顶部、浏览器标签页 favicon 如需设置也使用同一已选资产；侧栏横标宽约104–116px，高≤36px，保持长宽比；身份入口宽约160px。不可拉伸、套彩色底块、重复旁边文字。小图标采用统一 Lucide 风格（先检查现有库，优先复用），16/18/20/24px，描边1.75px 左右，不使用 emoji 充当常规功能图标。仅装饰图标 aria-hidden，单独图标按钮必须有可读名称。

页面、侧栏、导航栏、图表背景均 #FFFFFF。禁止米白整页、蓝/绿大色块、渐变、玻璃拟态、光晕、花哨插画、彩色功能卡片、大量胶囊及无用 AI 星光。选中导航允许非常浅的局部填充，内容区以留白、标题与细线区分。普通分区不投影，弹窗适量阴影。不要把所有分区都变成卡片；只有编辑对象、独立交互、确认和对照确有必要时使用边框。

## 3. 字体、空间与栅格

不外发字体请求。Windows 优先 Microsoft YaHei UI，macOS PingFang SC，Linux Noto Sans CJK SC；数字使用 tabular-nums。标题28px/1.35/600，区标题18px/1.5/600，教师正文14px/1.65，学生16px/1.75，辅助13px/1.5，小标12px，数据32px/1.2/600；不得滥用全粗体。数学题干公式可用20–24px，正文数学随字高。栅格4px，常用 8/12/16/24/32/40/48px；侧栏208px，顶栏64px，内容左右32px（1366下24px），最大宽1480px；阅读/作答区域≤860px，聊天正文≤800px。表格行48px，按钮38px（小32，大44），输入38px，文本域至少160px；普通圆角4/6/8px，避免全圆按钮，头像/圆点例外。主按钮每个操作区域通常一个，次操作描边或文本；危险按钮仅真实破坏性确认使用错误色。禁用时同时 disabled 与可见原因（必要时）。

1920×1080为参考，1440×900、1366×768必须可用。最小桌面参考宽1280；较窄桌面收缩图表列和工具区，允许图谱画布自身滚动/缩放、表格自身横向滚动；主页面不得整体横溢。大弹窗宽 min(1180px, calc(100vw - 64px))，高不超过 calc(100vh - 64px)，内部滚动，底部操作固定。证据抽屉宽520–640px；狭窄窗口可改成同一弹窗。移动端专项适配不属于比赛范围。滚动时导航不遮内容；固定页头下锚点保留64px空间。动画120–180ms，仅展开、焦点或状态反馈，尊重 prefers-reduced-motion。

编辑弹窗：顶部对象与基础版本（必要时历史），左任务组列表及可编辑文本，右候选材料/预览，底部取消/检查并发布；拖动有上下移动按钮作为替代；历史、已完成、进行中不可修改项显式标锁。证据抽屉：标题、对象/节点、证据正文、可展开版本出处；不出现整份 JSON。模型设置以独立弹窗/抽屉呈现，不在聊天正文泄露地址密钥。提醒在顶部 bell 弹层，点击定位业务页，不增加一级导航。

## 5. 文案与组件状态

禁止默认添加“系统通过智能分析帮助您……”“点击下方按钮开启……”之类已由标题/按钮表达的解释。标题直接写“学习计划”，按钮“继续学习”“查看依据”“检查并发布”。图表保留名称、单位、范围、分母/限制；必要状态有可理解原因。真实诊断、数学教学、推荐理由、受助确认、权限/错误说明不得被删。页面标题通常不加副标题，只有节点/范围等实际信息可用一行小字；不要每个分区都写产品宣传句。

控件至少 default/hover/focus/active/disabled/loading/error（适用者），加载保留布局骨架，按钮请求中禁重复提交并显示真实状态。空白无记录 ≠ 0分；缺证据 ≠ 未掌握；模型降级 ≠ 完整模型成功；审核成功 ≠ 发布成功。历史可用计划与待生成新计划必须标明不同状态。正文不能用过低对比度的文字模拟高级感。弹窗 Escape 关闭（有未保存修改先确认），焦点进入、Tab 环、关闭回原触发元素；确认卡明确接受/拒绝，不默认接受。图表有可访问的表格/文字数据，触控非本次要求但键盘可操作。

## 6. 验收与禁止自行发挥

DSH 必须引用 CSS token；禁止在页面 CSS 中新增无依据 HEX/渐变；固定图标库、公共组件和字号层级。视觉走查截图必须覆盖两身份、每一级页面、学生画像子页、微课堂、三题型、编辑/证据/确认弹窗、失败/空/审核中/历史状态。至少 1920×1080、1440×900、1366×768；检查主页面溢出、裁切、字体、焦点、对齐、边距、长中文/公式、表格滚动、禁用、实际选中颜色。实际正式产品截图与本包参考原型区分。视觉审查由设计负责人对照图片与规范进行，技术测试不能替代审美复核。若需要变更已确认色值或白底，先提出理由，不擅自修改。Logo 已由用户选定。浏览器截图与清晰度待实际验收。
